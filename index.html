Ключ ИИ

Ключ Gemini API нужен, чтобы ИИ распознавал еду по фото и описанию. Нажмите «?», если ещё нет ключа.

Как получить ключ (1–2 минуты)

  1. Откройте aistudio.google.com/apikey.
  2. Войдите в свой аккаунт Google (Gmail).
  3. Нажмите Create API key («Создать ключ API»). Если спросят проект, выберите Create API key in new project.
  4. Скопируйте появившийся ключ, он обычно начинается с AIza….
  5. Вернитесь сюда, вставьте ключ в поле ниже и нажмите «Сохранить ключ».
В России сайт Google AI Studio открывается только через VPN, но он нужен лишь один раз, чтобы получить ключ.

Ключ хранится только в вашем браузере. Никому его не передавайте. У бесплатного ключа есть лимиты запросов в минуту и в сутки. Названия кнопок на сайте Google могут немного отличаться.
